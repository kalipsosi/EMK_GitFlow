# АИС «Электронная медицинская карта»

Учебный проект по МДК 02.02. Хранение и обработка медицинских данных пациентов: история болезни, результаты обследований, назначения.

## Модель ветвления – Git Flow

| Ветка | Назначение |
|---|---|
| `main` | только стабильные выпущенные версии, каждая помечена тегом |
| `develop` | интеграция готовых функций следующей версии |
| `feature/*` | разработка одной функции, создается от `develop` |
| `release/*` | подготовка квартального релиза: тестирование, SAST, DAST, аудит ПДн |
| `hotfix/*` | срочное исправление рабочей версии, создается от `main` |

Версии выпускаются раз в квартал. Требования к проверкам безопасности – в [docs/SECURITY.md](docs/SECURITY.md), история версий – в [CHANGELOG.md](CHANGELOG.md).
