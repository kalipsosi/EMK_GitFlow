# Проверки безопасности релиза

Выполняются в ветке `release/*` перед слиянием в `main`.

- [x] Регрессионное и нагрузочное тестирование
- [x] Статический анализ кода (SAST): SQL-инъекции, XSS, небезопасная работа с данными
- [x] Динамическое тестирование (DAST) работающего приложения
- [x] Аудит защиты персональных данных: шифрование при хранении и передаче, права доступа, журнал действий пользователей

В ветках `feature/*` базовые проверки выполняет CI при каждом коммите. В ветках `hotfix/*` проводится сокращенная проверка только измененной части.
